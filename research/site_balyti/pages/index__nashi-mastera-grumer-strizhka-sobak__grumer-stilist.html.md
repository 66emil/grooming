# Яна - м. Марксистская

ТОП-Грумер стилист Яна - филиал салона "Балути" Марксистская.

Грумер Яна – работает в салоне “Балути” с 2012 года.

Грумер. Зоопсихолог.

Академия Скрябина.

Зоопарикмахер - универсал. Профессионал очень высокого уровня, что подтверждается большим количеством благодарных клиентов и записью на месяц вперед.

Регулярно повышает квалификацию на семинарах и тренингах​. Учавствует в конкурсах.

Прекрасно владеет различными техниками стрижки, тримминга и креативного окрашивания, уз-чистка зубов.

Яна - профессиональный заботливый грумер.

+ Породный триминг жесткошерстным породам собак.

+ Домашний тримминг, работает с мягкой шерстью.

+ Стрижка собак, кошек. Исправление неудачных стрижек. Подбор красивой стрижки для питомцев.

+ Гигиеническая стрижка.

+ разбор сложных колтунов

+ Работа с крупными и агрессивными собаками.

+ Стрижка маленьких щенков с заботой и со знаниями зоопсихолога.

+ Срижка старых или больных животных

+ Гигиенические процедуры.

+ Спа для животных

+ Чистит зубной камень. Без седаци.

+ Стрижка лошедей и пони. Креативный узор.
