## Старый сайт всё-таки есть

https://balyti.ru/ работает. Это CMS MODX, в подвале «© 2010–2025». Есть разделы: услуги, цены (отдельно для собак и для кошек), мастера, отзывы, галерея, новости, акции, советы, вакансии, курсы груминга, аренда. Кнопка записи ведёт на YCLIENTS.
Компания ссылается на этот сайт в ответах на отзывы как на «онлайн-запись». Сайт обойдён целиком, подробности в `site_balyti/README.md`.
